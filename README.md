# Toko Sepatu Nayla 👟🌸

Aplikasi web manajemen data toko sepatu berbasis Laravel dengan konsep MVC dan Eloquent ORM.

## Tentang Project
Aplikasi ini dibuat sebagai tugas mata kuliah Pemrograman Berbasis Web (PBW B). Toko Sepatu Nayla adalah sistem CRUD untuk mengelola data sepatu dan kategori sepatu.

## Fitur
- Menampilkan data sepatu beserta kategori
- Tambah, edit, dan hapus data sepatu
- Upload gambar sepatu
- Pencarian sepatu berdasarkan nama dan merek
- Filter sepatu berdasarkan kategori
